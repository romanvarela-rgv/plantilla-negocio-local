# Instrucciones para agentes

Antes de cualquier tarea, leé los documentos de /docs. Toda decisión debe respetarlos. Si algo contradice la documentación, avisá antes de continuar.

## Comandos
- `npm test`: tests (node --test, sin dependencias)
- `npm run build`: genera `dist/` desde `negocio/negocio.json`
- `npm run dev`: build + servidor en http://127.0.0.1:4321

## Documentos
- `docs/01_PRD.md`: qué se construye y por qué
- `docs/02_DESIGN_SYSTEM.md`: cómo se ve y cómo se escribe
- `docs/03_ARCHITECTURE.md`: stack, estructura y despliegue
- `docs/04_AGENTS.md`: reglas para agentes de IA
- `docs/05_SECURITY.md`: autenticación, permisos y secretos
- `docs/06_CODE_STYLE.md`: convenciones de código y commits
- `docs/07_DATABASE.md`: modelo de datos
- `docs/08_API.md`: endpoints e integraciones
